# Portal de Entretenimento Digital 🎬

Projeto prático para a **Agenda 13 - Desenvolvimento de Sistemas I**. Uma página temática dividida em três seções (Filmes, Músicas e Games) estruturada lado a lado.

## 🚀 Tecnologias e Recursos
- **HTML5:** Tags semânticas, classes, IDs e descrições `alt`.
- **CSS3 (Flexbox):** Layout responsivo em 3 colunas.
- **Folhas de Estilo:** Uso de CSS Reset (Eric Meyer), Inline, Interno e Externo.

## 📂 Estrutura de Arquivos
- `index.html` (Interface principal)
- `Paisagem.css` (Estilos e comentários)
- `reset.css` (Reset do Eric Meyer)
- Imagens do projeto (`.png`)
